# Knowledge folder — the evidence behind the rules

`CLAUDE.md` holds the rules. This folder holds the proof behind them.

Read the file that matches the job in front of you. Do not read all of them.

| Read this | Before you |
|---|---|
| [`data-sources.md`](data-sources.md) | Connect, change, or debug any data source |
| [`metric-definitions.md`](metric-definitions.md) | Add or change any number that reaches the brief |
| [`money-facts.md`](money-facts.md) | Make a paid call, estimate a cost, or run a test that reaches the AI step |
| [`n8n-environment.md`](n8n-environment.md) | Make your first n8n call, follow the ten build steps, or when a key or node type fails |
| [`n8n-gotchas.md`](n8n-gotchas.md) | Write a Code node, a cross-node expression, or a node name |

Two of these are deliberately empty. `data-sources.md` and `metric-definitions.md` get
filled the first time something is actually proven, not before.

## Rules for this folder

- **Add evidence here, not to `CLAUDE.md`.** `CLAUDE.md` gets the instruction only.
- **Never move a number, price, date, quote or measurement into `CLAUDE.md`.** That is how
  two files start to disagree. `CLAUDE.md` may name a flag, a tool or an id it needs to
  state the rule. It carries no evidence beyond that.
- **Paste, do not retype.** Rewriting is how facts get lost.
- **The session wrap-up triggers and the spending guard live in the global
  `C:\Users\AMD\.claude\CLAUDE.md`**, not here and not in `CLAUDE.md`.
